Projects Ideas

The following outlines my primary research and supervision interests for both undergraduate and postgraduate student projects.

  • Machine Learning for Enhancing Network Performance: Developing data-driven models to predict traffic congestion, optimize routing pathways, or dynamically allocate resources to improve overall Quality of Service (QoS).
  • Machine Learning for Network Vulnerability Detection: Building intrusion detection models to identify malicious network behavior or unauthorized access attempts in real time.
  • Technology-Enhanced Learning (TEL) & AI Applications: Creating interactive educational tools, gamified learning environments, or AI-driven platforms (including AR/VR integration) that adapt content and feedback based on student performance.
  • Securing LLMs Against Prompt Injection Attacks: Investigating adversarial prompt injection vulnerabilities in large language models and developing defense mechanisms or detection pipelines to neutralize malicious prompts.
  • Machine Learning for Adaptive Multimedia Delivery: Designing intelligent bitrate adaptation algorithms and dynamic streaming models that adjust video quality on the fly based on predicted network fluctuations and user QoE metrics.
  • Immersive AR/VR Applications: Developing augmented or virtual reality environments for spatial simulations, remote collaboration, virtual labs, or interactive training tools.
  • Automated Network Topology Emulation via LLMs: Constructing LLM-powered tools that convert natural language network requirements into executable network emulation configurations (e.g., GNS3, Mininet, or Ansible playbooks) paired with automated validation scripts.

If you have an original or innovative project idea of your own, please feel free to run it by me so we can discuss its feasibility and scope!
